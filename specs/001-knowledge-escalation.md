# 001. База знаний и передача вопроса наставнику

## Цель
Сократить повторяющиеся объяснения наставника: один раз ответил, дальше отвечает помощник.

## Поведение

**Вопрос стажёра (`POST /api/chat`)**
1. Текст нормализуется: слова в нижний регистр, служебные слова и слова короче 3 букв отбрасываются, остальные режутся до 5 букв.
2. Для каждой записи базы знаний (доступной роли пользователя) считается `score = |слова вопроса ∩ слова записи| / |слова вопроса|`.
2a. Если настроен LLM и включён флаг `llm_answers`, он формулирует ответ только по найденным записям (см. 006); при сбое решают правила ниже.
3. Если `score >= KB_MIN_SCORE` (по умолчанию 0.5): ответ берётся из лучшей записи, вопрос сохраняется со статусом `answered_auto`, счётчик использования записи растёт.
4. Иначе: ответ не выдумывается. Вопрос сохраняется со статусом `pending`, стажёр получает честное сообщение.
5. Если в вопросе есть «отгул» или «доступ», в ответе приходит `suggested_action` (`leave_request` / `access_status`), по которому интерфейс предлагает действие.

**Дайджест наставника (`GET /api/mentor/digest`)**
- Только вопросы `pending` стажёров этого наставника.
- Одинаковые по смыслу вопросы (одинаковый набор основ слов) группируются: «спросили 2 стажёра».

**Ответ наставника (`POST /api/mentor/digest/answer`)**
- Создаёт запись базы знаний (`source = mentor`, `audience` = `all` или `mentor`).
- Каждому закрытому вопросу в чат стажёра добавляется сообщение «Наставник ответил…».
- Закрывает **все** `pending`-вопросы той же группы у стажёров этого наставника (`answered_by_mentor`).
- Повторный ответ на уже закрытый вопрос: 404.

**Метрики (`GET /api/metrics`)**
- `auto_rate` — доля вопросов, закрытых без наставника.
- `reused_mentor_answers` — сколько раз стажёры получили готовый ответ наставника.
- `mentor_minutes_saved` = ответы без наставника × `MINUTES_SAVED_PER_ANSWER`.

## Граничные случаи
- Пустое сообщение или длиннее 500 символов: 400.
- Вопрос без значимых слов: поиск возвращает «ничего не найдено», вопрос уходит наставнику.
- Наставник тоже может спросить базу знаний, но его вопросы не попадают в дайджест и метрики.

## Критерии приёмки
- [x] Неизвестный вопрос не получает выдуманного ответа.
- [x] Два одинаковых вопроса дают одну строку дайджеста со счётчиком 2.
- [x] После ответа наставника тот же вопрос от стажёра закрывается мгновенно.
- [x] Метрики отражают повторное использование.
